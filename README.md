# Harvard CS50x 2025 Problem Sets

This repository contains my solutions to the problem sets for **Harvard's CS50x 2025: Introduction to Computer Science** course.

---

## Weeks
### Week 0: Scratch

My journey with CS50x kicked off in Week 0 with Scratch, a fun and visual way to start programming. For my project, I created a game called Odysseus in the Land of the Lotus Eaters. It's pretty simple: I control Odysseus and have to save my soldiers from touching a poisonous lotus flower. Every time I succeed, the game gets a little faster, making it more challenging.

1. <a href="https://scratch.mit.edu/projects/1181214369/">**Odysseus in the Land of Lotus Eaters**</a>

### Week 1: C

Here we jumped into C, a much more powerful but also trickier language. This week was all about the fundamentals: I learned about data types, how to use conditionals and loops to control my program's flow, and how to write actual lines of code. It was a really rewarding start overall.

1. <a href="https://github.com/yoyok-yahb/cs50-psets/blob/cs50x/week1/hello.c">**Hello, World**</a> - Introduction to this world of programming
2. <a href="https://github.com/yoyok-yahb/cs50-psets/blob/cs50x/week1/me/hello.c">**Hello, It's Me**</a> - Takes user input to greet them
3. <a href="https://github.com/yoyok-yahb/cs50-psets/blob/cs50x/week1/mario-more.c">**Mario**</a> - Creating the Mario pyramids using using loops
4. <a href="https://github.com/yoyok-yahb/cs50-psets/blob/cs50x/week1/cash.c">**Cash**</a> - Calculating change owed for a shop
5. <a href="https://github.com/yoyok-yahb/cs50-psets/blob/cs50x/week1/credit.c">**Credit**</a> - Checking the validity and issuing company of a credit card number
